# data-science-portfolio

My data science portfolio, published with GitHub Pages:

**https://kelvin-chan-ka-wai.github.io/data-science-portfolio/**

The site is a single `index.md` page (name, introduction, technical skills, project showcase with
all three visualisations, findings, limitation, links and status) plus the `assets/` images.
GitHub Pages serves it from the `main` branch, root folder.

- `REFLECTION.md` - the submitted reflection (about 200 words), the feedback-to-commit table and
  the responsible-sharing check.
- `REVIEW.md` - the peer review the portfolio responds to, so the feedback can be read in full.

The showcased project lives in
[data-science-project](https://github.com/Kelvin-Chan-Ka-Wai/data-science-project).

Author: CHAN KA WAI (mc64933), CISC7204 Data Science and Data Visualization, University of Macau.
